# content/source/symbols

Ovdje se postavljaju **izvorni (autoritativni) materijali** – pojedinačni SVG simboli.

Directory for the authoritative source materials. It was **empty** when the MVP was
built (see `docs/SOURCE_ANALYSIS.md`). Add files here and run `pnpm import:all`;
the import pipeline (`docs/IMPORT_PIPELINE.md`) inventories them and reports what
needs review. `README.md` files are ignored by the pipeline.
